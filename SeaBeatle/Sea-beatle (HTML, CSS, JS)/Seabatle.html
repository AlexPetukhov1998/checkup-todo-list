"Этапы игры"

  • 1. Расстановка кораблей: выберите количество кораблей в настройке "Количество кораблей", кликните по своему полю, чтобы расставить корабли или нажмите кнопку "Случайно расставить корабли". Корабли нельзя ставить рядом друг с другом.
  • 2. После расстановки кораблей нажмите кнопку "Начать игру".
  • 3. Ваш ход будет первым — кликните по полю противника. После вашего хода ИИ выстрелит по вашему полю.
  • 4. Игра закончится, когда вы или противник потопите все корабли. Для начала новой игры нажмите кнопку "Новая игра".
